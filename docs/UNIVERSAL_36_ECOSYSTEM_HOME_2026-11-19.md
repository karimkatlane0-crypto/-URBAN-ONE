## Stati connessione
NOT CONNECTED → CONFIGURED → TESTED → VERIFIED → RELEASED.
Un link esterno non è un'integrazione. Una chiave configurata non è una connessione verificata. Nessun provider, servizio regolamentato o transazione può essere dichiarato attivo senza test end-to-end ed evidenza indipendente.

## Qualità e miglioramento regolare
- Quality gates: accessibilità, mobile, sicurezza, privacy, accuratezza delle fonti, localizzazione, performance, resilienza e regressione.
- Aggiornamenti: monitoraggio, changelog, data ultimo controllo, owner, test automatici e revisione umana.
- Import/export/circolazione: validazione paese-specifica, dogana, IVA, origine, classificazione, licenze, sanzioni, documenti e requisiti di trasporto; usare fonti ufficiali aggiornate.
- Governance: BUILD → VERIFY → RELEASE → SCALE. Nessun merge o rilascio automatico; approvazione umana esplicita.

## Limitazioni note
GMAPS in questa prima pagina usa l'URL pubblico di Google Maps; non dimostra Google Maps Platform API, billing o key. INSIGHTS resta demo se non esiste un provider autenticato e testato. SEVA/SYNAPSY restano separati e i rispettivi gate non si chiudono tramite sola navigazione.
