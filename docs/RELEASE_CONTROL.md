## Google Play release control

The authoritative store checklist is `docs/PLAY_STORE_RELEASE.md`.

Release states must be evidence-based:

1. `SOURCE-READY` — source/configuration exists.
2. `CI-PASS` — tests and required build gates pass.
3. `PLAY-READY` — exact AAB is signed, verified, tested and policy/store content is ready.
4. `SUBMITTED-FOR-REVIEW` — Play Console confirms submission.
5. `IN-PRODUCTION-ROLLOUT` — Play Console confirms production rollout has started.
6. `PRODUCTION-PUBLISHED` — Play Console confirms production availability.

Do not collapse these states into one claim.
